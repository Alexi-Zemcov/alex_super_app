# module_contracts

Пакет с минимальными публичными контрактами между shell и продуктовыми модулями.

## Основные точки входа

- `lib/module_contracts.dart` - публичный export пакета
- `lib/src/app_module_descriptor.dart` - контракт подключения модуля к shell
